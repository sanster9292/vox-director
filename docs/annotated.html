Frontmatter

name / description

name: vox-director-fal

Make a Vox-style video: a narrated explainer or ad built from torn-paper collage posters (halftone cut-outs, bold flat colour, baked-in headlines) with music and captions, end to end on fal.ai + local ffmpeg. Use ONLY when someone asks for a Vox-style or Vox-styled video, or names Vox as the look they want. Don't use it for other collage, motion-graphics or video requests that don't ask for the Vox style. Handles real places from reference photos, crisp photographic people, and mixed-language narration (e.g. Urdu + English). NEW

Plain EnglishThis text is all Claude sees when deciding whether to load the skill. It now says to load the skill only when you ask for the Vox look, and names what to ignore.
Watch out"Make a collage reel" or "animate this poster" won't load the skill anymore. Say "Vox-style" when you want it.
§1

How it works

Turns one topic into a finished Vox-style paper-collage film: each beat is a torn-paper collage poster with a baked-in headline, animated by an image-to-video model, then cut together with narration, a music bed and captions. All generation runs on fal.ai; editing runs on local ffmpeg.

The collage look is born in the image step (a rich, layered poster with clear cut-out edges and shadows), and motion is added after by animating that poster. A weak keyframe can't be rescued by animation, so most of the care goes into keyframes, and keyframes are cheap to re-roll.

Before writing any prompt read references/prompt-guide.md; for story, references/beat-layer.md; for models, prices and every known failure, references/fal-models.md.

No model is built in. Each project names its models in beats.json, chosen when you write the beat map: the person's pick first, otherwise open-source models first, whatever country they come from. Among the open models that do the job, pick the cheapest, at the cheapest settings that still look right. A stage with no model stops and says which field to fill. falq.fit() adapts each request to the chosen model's own input fields. NEW

Plain EnglishImage quality caps the whole film. Animation adds time, not craft, so spend your re-rolls on keyframes, which cost cents.
Plain EnglishThere are two filters, in order. First, is it open source? Where a model comes from isn't a factor. Then, of the open models that pass a one-keyframe test, which is cheapest?
For youIn practice Qwen (Alibaba) and FLUX klein (Black Forest Labs) compete on equal terms, and the cheaper one wins whenever the test keyframe looks right.
§2

Prerequisites

  • fal key. Scripts read FAL_KEY, or on macOS a Keychain item named fal-api-key. If neither exists, run zsh scripts/set_key.sh fal-api-key in your own terminal (input hidden). Never paste a key into chat; if one is pasted anyway, store it and rotate it later.
  • Photo search keys (optional). Same pattern for pexels-api-key (free) and google-maps-api-key (Places API). Without them, those sources are skipped. NEW
  • ffmpeg + ffprobe. Python 3 standard library is enough.
  • Captions: on macOS the Swift renderer compiles itself on first use (Xcode CLI tools). Elsewhere pip install pillow, or "captions": false.
  • Where to save: ask, or use ~/Videos/vox/<project>/. One folder per project.

Every script takes the project folder first. Every paid stage supports --dry-run (jobs + cost estimate, submits nothing), --ids 1,4 (redo only those beats) and --draft (cheap ideation pass in <project>/draft/).

Plain EnglishThe Keychain route keeps the key out of chat, shell history and plain-text files. It's the safest of the three options.
Watch outpython.org builds on macOS often lack CA certificates, which gives CERTIFICATE_VERIFY_FAILED. falq.py falls back to /etc/ssl/cert.pem; the permanent fix is "Install Certificates.command".
§3

Workflow

1 · Beat map → approval gate

Write beats.json, then show the beat map as a table (headline, narration, collage contents, camera/motion), the model roster with each model's license NEW, and the estimated cost. Wait for a go-ahead.

  • Ask what matters: aspect (9:16 Reels/Shorts, 16:9 YouTube), length, narration language(s), history vs present day.
  • ~5 s per beat; 30 s ≈ 6 beats; ≈12 English words per line, or assemble.py slows the clip.
  • Beat 1's headline is the hook. Vary camera between adjacent beats; end on a hold.
  • Be specific: real places, foods, vehicles, crafts, everyday people. Generic collage reads as stock.
  • Everyday people, not celebrities — video models often refuse public figures.

Ask: draft first, or straight to the final film? NEW A draft is a cheaper, lower-quality pass for trying ideas. Show both estimates.

Plain EnglishThe gate is the cheapest moment to change direction. Nothing has been spent yet, and you approve the story, the models and the budget together.
For you12 words per 5-second beat is tight. For a Clothing Essentials ad, write it as one punchy claim per beat, not full sentences.
Plain EnglishThe draft lives in its own folder, so it can't overwrite anything. Its beats.json and references/ are links to the project's own, so an edit to the plan applies to both.
Watch outClips are about 70% of the bill. A 480P draft costs roughly a third of 1080P per second on the tested video model, which is where the draft saves most.

2 · Reference photos for real places and people NEW

Anything real and specific (a city, street, landmark, restaurant, shop or real person) gets real photos before generating:

  1. Ask for the person's own photos first.
  2. If they have none, ask permission before searching the web.
  3. Search in this order: Google Maps place photos → Pexels → photos geotagged at the place on Wikimedia Commons → Commons keyword search.
  4. People are never searched for — their photos come only from the person asking, with consent.
python3 scripts/refs.py add <project> shop.jpg ~/Downloads/shop.jpg --credit "their photo"
python3 scripts/refs.py search "Ghanta Ghar Faisalabad"      # or --source google|pexels|geo|commons
python3 scripts/refs.py get <project> clocktower.jpg <id from the results>
python3 scripts/refs.py sheet <project>

Add "refs": [{"file": "...", "desc": "..."}] to the beat; desc says what to keep. Every saved photo gets a line in references/CREDITS.md with source, author and licence.

Plain EnglishWithout a reference, the image model invents a building that looks plausible and is wrong. A beat with refs automatically goes to image.edit_model.
Plain English"Geotagged" works by finding the place on OpenStreetMap, then pulling Commons photos taken within 400 m of it. That's how you get the actual street, not something that shares its name.
Watch outGoogle Maps photos are used only as references for the image model. Check Google's terms before showing one unaltered. Commons usually needs credit; Pexels doesn't.
For youFor a Clothing Essentials shoot, your own product and store photos take priority. The add command logs them as yours.

3 · Keyframes (1K) → look → fix

python3 scripts/keyframes.py <project> --dry-run
python3 scripts/keyframes.py <project>
python3 scripts/review.py <project> keyframes

Check every keyframe: headline spelled right, no stray quotes, nothing poking into the banner; dense layered cut-outs; landmark matches; calm bottom fifth for captions. Re-roll with --ids N, or one targeted fix: hires.py --ids 1 --fix "...". Add --draft to any of these for the draft pass.

4 · 2K pass for crisp people

python3 scripts/hires.py <project>

Re-renders each approved keyframe at 2K, layout kept, people turned into sharp printed-photo cut-outs. Skipping it is the main cause of blurry "AI" faces. Skipped in a draft; in the final run it starts from the approved draft keyframes when there are no final ones yet. NEW

Plain EnglishAt 1K a face is only a few dozen pixels tall. The 2K pass gives the video model real detail to keep.
For youOn Qwen-Image-Edit, fit() turns "2K" into a 2048 px long side through image_size. Same intent, different field name.
Watch outThe edit model occasionally nudges an element. Re-check the review sheet after the 2K pass.

5 · Clips → look at every one

python3 scripts/clips.py <project> --dry-run
python3 scripts/clips.py <project>
python3 scripts/review.py <project> clips
python3 scripts/review.py <project> title <beat>

Use the resolution that keeps people sharp (1080P on most models); 480P is cheaper but visibly soft. The usual defect is something drifting over the headline; rewrite that beat's motion to keep it low ("the kites stay in the sky band below the banner") and --ids N. Earlier takes are kept as clipN_take1.mp4.

Watch outClips are about 70% of the bill. Show the dry-run estimate again before this stage.
Plain EnglishIf the model only offers set lengths (say 5 s or 10 s), fit() rounds up to the next allowed length and prints a note. Assembly trims the extra.

6 · Narration + music

python3 scripts/audio.py <project>

One narration file per beat. Pick voice and delivery in tts.params. For code-switched narration write each language in its own script inside narration and describe the accent in style_instructions. Music: drop your own audio/music.mp3 and it is reused NEW, or set music.model + music.prompt.

7 · Captions

captions.py uses each beat's caption, else narration. For mixed scripts, caption in Latin script (Roman Urdu / Hinglish).

8 · Assemble + verify

python3 scripts/assemble.py <project>
python3 scripts/review.py <project> final

Claude can't listen to the mp4 — ask the person to check pronunciation. Report: path to final.mp4, a line per beat, fixes made, what's still imperfect, credit note, and spend as a range.

For youPunjabi or Urdu with English is exactly this path: native script in narration, Roman script in caption. It fits the comedy channel too.
Watch outVoice names belong to one TTS model. After switching tts.model, pick a voice that model actually has.
Plain EnglishMixed right-to-left and left-to-right text jumbles its order when a line wraps. That's why captions use Latin script.

  "mix": {"music": 0.6, "voice": 1.25},
  "captions": true,

Required: style_block; beat fields id, bg, scene, camera, motion; a model for each stage you run (music optional with your own file).

How fit() adapts requests NEW

The stage scripts write one neutral request; falq.fit(endpoint, payload) reads the endpoint's input schema (cached a week in ~/.cache/vox-director-fal/schemas, no key needed) and reshapes it:

Script sendsModel expectsfit() sends
aspect_ratio 9:16 + resolution 2Kimage_size (Qwen, FLUX){"width": 1152, "height": 2048}
sameonly enum sizesportrait_16_9 (nearest)
resolution 2kenum 0.5K/1K/2K/4K2K (case matched)
image_urls [a, b]image_urla, with a note
prompttext (TTS)text
duration 4enum "5","10""5", with a note
duration 3range 5–155, with a note
any field the model lacks—dropped, with a note

If the schema can't be fetched, the payload goes out unchanged.

Plain EnglishThis is what makes "change the model in one line" true. Before, a wrong field name was silently ignored by some models, which wasted a paid run.
Watch outRead the notes on the first --dry-run with any new model. A dropped field is where a mismatch shows up.
Watch outEvery row was tested against mock schemas shaped like the real ones. It hasn't run against live fal yet because fal wasn't reachable from this session.
§7

Costs and price traps

Every paid stage spends real money. Show the --dry-run estimate at the beat map and again before clips (~70% of the total). Budget one or two re-rolls per film. 401/403 = wrong key; 402 or "insufficient balance" = stop and tell the person.

  • The pricing API returns the base tier. H3 Max Turbo reports $0.015/s, the 480P promo price; 1080P costs several times more. Read the model page.
  • Token-billed models report unit_price: 1, unit: units; the real per-second price is on the page.
  • Launch promos expire (H3's 40% discount ended 15 Oct 2026). Quote ranges.
Watch outThe dry-run total is a floor, not a quote. For video, check the model page's per-resolution price.
Plain Englishclips.py carries its own per-resolution price table for the tested models. For others, set video.price_per_second.
§8

Gotchas

  1. SSL on macOS python.org builds — auto fallback; permanent fix via Install Certificates.
  2. ffmpeg without drawtext/libass — captions are rendered to PNG and overlaid.
  3. Mixed-script captions jumble on wrap — caption in Latin script.
  4. Moving elements cover the headline — keep motion low; check review.py title.
  5. Spires poke into the banner ("TO" read as "TQ") — hires.py --ids N --fix.
  6. Stray quotation marks around headlines — re-roll that keyframe.
  7. Clip length ≠ narration length — assemble slows the clip, never freezes it.
  8. Video models add their own soundtrack — assemble never uses clip audio.
Plain EnglishEach of these cost a re-run while the skill was being built. Read the list before debugging anything.
§9

Not supported yet

This skill doesn't yet re-style a talking-head video, build a film around one photo of a person or product, put a talking presenter on screen, or animate cut-out pieces one by one. If someone asks, say so plainly and offer the closest thing it can do: a collage film on their topic, using their photo as a reference image where that helps.

For youA film built around one product photo is the gap that matters most for Clothing Essentials, so it's the one to add first. The edit_model slot and reference handling already exist here.
